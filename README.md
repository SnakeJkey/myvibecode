# Game Radar

Настольное приложение, которое показывает текущие и предстоящие события и обновления в играх:

1. Arknights: Endfield
2. World of Tanks (Europe)
3. Minecraft
4. Hearts of Iron IV

Для каждой игры есть вкладка с двумя подразделами: **Текущая версия** и **Предстоящая**. Интерфейс поддерживает светлую и тёмную темы. Выбор запоминается, а по умолчанию берётся тема системы.

## Запуск двойным кликом

### Вариант 1. Готовая программа (`.exe`), Node.js не нужен

1. Откройте на GitHub вкладку **Actions**, выберите последнюю успешную сборку «Сборка Game Radar».
2. В самом низу страницы, в разделе **Artifacts**, скачайте `GameRadar-Windows` (для Mac `GameRadar-macOS`, для Linux `GameRadar-Linux`).
3. Распакуйте архив. Внутри два файла для Windows: `GameRadar-portable.exe` (запускается двойным кликом, без установки) и `GameRadar-Setup.exe` (установщик с ярлыком в меню «Пуск»).
4. Перенесите `GameRadar-portable.exe` на рабочий стол и запускайте.

При первом запуске Windows может показать окно «Windows защитила ваш компьютер», потому что программа не подписана. Нажмите «Подробнее», затем «Выполнить в любом случае».

### Вариант 2. Запуск из папки проекта

Нужен [Node.js](https://nodejs.org) 20 или новее (версия LTS).

1. Скачайте проект и распакуйте архив.
2. Дважды щёлкните **`Game Radar.bat`** (Windows), **`Game Radar.command`** (macOS) или запустите **`./game-radar.sh`** (Linux).
3. При первом запуске программа сама установит нужные компоненты (1-3 минуты, нужен интернет), затем откроется окно. Дальше окно открывается сразу.

Чтобы запускать с рабочего стола, дважды щёлкните **`Desktop shortcut.bat`**. Он создаст ярлык «Game Radar» с иконкой. Папку проекта после этого не удаляйте и не переносите.

На Mac, если файл не открывается, один раз выполните в Терминале `chmod +x "Game Radar.command"`.

## Запуск из командной строки

```bash
npm install      # один раз, скачает Electron
npm start        # откроет окно Game Radar
```

Размер и положение окна запоминаются. Ссылки на новости открываются в браузере по умолчанию.

## Сборка установщика самостоятельно

```bash
npm run dist:win     # Windows: GameRadar-Setup.exe и GameRadar-portable.exe в папке dist/
npm run dist:mac     # macOS: .dmg
npm run dist:linux   # Linux: .AppImage
```

Собирать лучше на той ОС, для которой нужен установщик. Автоматическая сборка для всех трёх систем настроена в `.github/workflows/build.yml`. Если создать тег вида `v1.0.0`, готовые файлы прикрепятся к релизу.

## Язык

Тексты показываются на русском. Arknights: Endfield отдаёт официальные русские новости. Для World of Tanks (EU), Minecraft и Hearts of Iron IV русских аналогов нет, поэтому английские тексты переводятся автоматически (Google, запасной сервис MyMemory). Оригинал виден при наведении на заголовок. Переводы кэшируются на диске, а если сервис перевода недоступен, остаётся английский текст с предупреждением.

## Полный текст новостей

Клик по карточке (или кнопка «Подробнее» в верхнем блоке) открывает окно во весь размер с полным текстом новости: заголовки, абзацы, списки, картинки. Внизу окна есть кнопка «Открыть на официальном сайте», она ведёт на ту же новость на официальном ресурсе (для Minecraft это страница на minecraft.net, для Hearts of Iron IV страница новости в Steam). Закрыть окно можно крестиком, кнопкой «Закрыть», клавишей Esc или кликом по затемнённому фону. Если текст новости получить не удалось, окно показывает краткое описание и кнопку перехода на сайт.

Иконки игр лежат в `public/icons/`.

## Запуск в браузере (запасной вариант)

```bash
npm run web      # http://localhost:3000
```

Переменные окружения: `PORT` (по умолчанию 3000) и `HOST` (по умолчанию 0.0.0.0).

Тесты: `npm test`.

## Источники данных

| Игра | Источник |
| --- | --- |
| Arknights: Endfield | официальный бюллетень (`web-news.gryphline.com`) и Steam |
| World of Tanks (EU) | RSS, раздел обновлений и календарь WoT Monthly на `worldoftanks.eu` |
| Minecraft | манифест версий и патчноуты Mojang |
| Hearts of Iron IV | новости Steam (патчи, беты, Dev Corner) |

Сервер кэширует ответы на 15 минут. Если источник недоступен, показываются последние сохранённые данные с предупреждением. Кнопка обновления в шапке запрашивает свежие данные принудительно.

Даты, помеченные «≈», рассчитаны по среднему циклу обновлений, а не объявлены официально. Время событий Endfield в бюллетенях указано по серверу, мы считаем его временем Америки и Европы (UTC-5).

## Структура

- `electron/`: окно настольного приложения и мост между интерфейсом и загрузчиками данных
- `Game Radar.bat`, `Desktop shortcut.bat`, `Game Radar.command`, `game-radar.sh`: запуск двойным кликом
- `lib/translate.js`: автоперевод с кэшем и запасным сервисом
- `lib/richtext.js`: разбор HTML и BBCode новостей в безопасные блоки для окна новости
- `server.js`: запасной вариант для браузера, статика и API (`/api/games`, `/api/games/:id`, `/api/games/:id/article?ref=…`, параметр `?refresh=1`)
- `lib/*.js`: загрузчики и парсеры источников, реестр игр, кэш
- `public/`: интерфейс (HTML, CSS, JS без сборки)
- `test/`: тесты (`node --test`)
